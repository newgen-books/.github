# NewGen Books

Read the classics in English, at your level — **[books.dev](https://books.dev)**

NewGen Books is a free web reader for English learners: public-domain classics in the original
and in simpler editions for A2–C1 readers, each with a measured CEFR level, tap-a-word
translation, narration with word-by-word highlighting and spaced review of the words you look up.

Contact: support@books.dev
